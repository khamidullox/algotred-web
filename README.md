# algotred-web

Движок бэктеста торговых стратегий (этап 1) и локальный сайт-оболочка над ним. Задание — в [TZ-backtest-engine.md](TZ-backtest-engine.md).

**Итог этапа 1 (17.11.2026).** Все восемь шагов ТЗ пройдены. На наборе `test` обе версии `BreakoutRetestV1` получили вердикт `REJECT` (PF 0,70, просадка 40–47%, мат. ожидание −0,23…−0,25 R), `TrendD1` как базовая линия тоже в минусе. Подробности — в разделе 12 ТЗ, журнал — в [EXPERIMENTS.md](EXPERIMENTS.md), отчёты — в `reports/test/`. Правила стратегий после этого заморожены: любая правка — новая стратегия с новым именем.

Сайт работает только локально (раздел 4а ТЗ): данные MT5 и прогоны на `dev` не хранятся в git. Поэтому автоматические деплои на Vercel отключены в `vercel.json`; чтобы включить их, сначала нужна выкладка с базой данных из `BACKLOG.md`.

Нужен Node.js 20 или новее.

```
npm install
npm test                                              # тесты
npm run typecheck                                     # проверка типов
npm run validate                                      # проверка CSV из data/raw
npm run backtest -- --strategy TrendD1 --dataset dev  # бэктест; стратегии: TrendD1, BreakoutRetestV1-A, BreakoutRetestV1-B
npm run dev                                           # сайт на http://localhost:3000
```

CSV из MetaTrader 5 кладутся в `data/raw/` под именами вида `EURUSD_H1.csv`. В git они не попадают. Проще всего загрузить их на странице «Данные»: она сама распознаёт имена экспорта MT5, показывает результат проверки и свечной график.

`npm run validate` завершается с кодом 0, если ошибок нет, и с кодом 3, если данные использовать нельзя. Предупреждения (пропуски, нулевой спред) на код не влияют.

Данные делятся на три набора по датам: `holdout` — последние 24 месяца, `dev` — первые 70% остального, `test` — последние 30%. Границы печатает `npm run validate`. Набор выбирается флагом `--dataset`, по умолчанию `dev`.

Набор `holdout` закрыт: без флага `--i-understand-holdout` команда `backtest` завершается с кодом 4. Каждый запуск на `test` и `holdout` дописывается в [EXPERIMENTS.md](EXPERIMENTS.md).

Каждый прогон сохраняется в `reports/<набор>/<время>_<стратегия>/`: `report.md` и `report.json` — отчёт по разделам 9–10 ТЗ (метрики, разбивки, bootstrap, стресс-тест, вердикт), `trades.csv` — список сделок для ручной сверки, `run.json` — всё, что посчитал движок. Прогоны на `dev` в git не попадают. Страница «Отчёты» показывает сохранённые отчёты; на странице «Данные» сделки любого прогона можно показать на графике: стрелка — вход, точка — выход, пунктир — стоп и тейк.

**Этап 2 (17.11.2026, раздел 16 ТЗ):** проверены ещё четыре стратегии (`BreakoutRetestV2-minstop`, `BreakoutRetestV2-breakeven`, `StrongLevelD1`, `RectangleV1`) — все закрыты на `dev` без выноса на `test`; идеи раздела 15 исчерпаны.

С этапа 2 каждая сделка несёт MAE и MFE — максимальный ход цены против позиции и в её пользу (колонки `mae_r` / `mfe_r` в `trades.csv`, раздел «Ход цены внутри сделки» в отчёте).

Движок (`src/engine/`) ведёт один счёт на все пары, исполняет сигнал по открытию следующей свечи, проверяет стопы на свечах M15 (или H1 для дневной стратегии) и считает спред, комиссию, проскальзывание и своп. Как именно — в уточнении к разделу 7 ТЗ.

Настройки — в `config/default.json`. Набор инструментов задаётся там же, в `symbols`: для каждого — число знаков в цене, размер контракта, с какой стороны доллар (`quote` для EURUSD или XAUUSD, `base` для USDJPY или USDCAD), свопы в пипсах за ночь со знаком, как в MT5 (отрицательный — платим), и при необходимости свои минимальный спред и комиссия вместо общих из `costs`. Файлы `data/raw/<SYMBOL>_<TF>.csv` нужны для каждого инструмента из списка; кроссы без доллара (EURJPY) пока не поддерживаются. Сейчас инструментов восемь: EURUSD, GBPUSD, USDJPY, AUDUSD, NZDUSD, USDCAD, USDCHF, XAUUSD. У золота `timeZoneCheck: false` — его неделя закрывается не как у валют, и часовой пояс по нему не проверяется. Границы `dev` / `test` / `holdout` закреплены в секции `datasets` и не сдвигаются при новой выгрузке. Параметры стратегий в конфиг не вынесены: они зафиксированы в ТЗ.
