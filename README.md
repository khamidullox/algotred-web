# algotred-web

Движок бэктеста торговых стратегий (этап 1) и локальный сайт-оболочка над ним. Задание — в [TZ-backtest-engine.md](TZ-backtest-engine.md).

Нужен Node.js 20 или новее.

```
npm install
npm test                                              # тесты
npm run typecheck                                     # проверка типов
npm run validate                                      # проверка CSV из data/raw
npm run backtest -- --strategy TrendD1 --dataset dev  # бэктест (BreakoutRetestV1 — шаг 7, пока нет)
npm run dev                                           # сайт на http://localhost:3000
```

CSV из MetaTrader 5 кладутся в `data/raw/` под именами вида `EURUSD_H1.csv`. В git они не попадают. Проще всего загрузить их на странице «Данные»: она сама распознаёт имена экспорта MT5, показывает результат проверки и свечной график.

`npm run validate` завершается с кодом 0, если ошибок нет, и с кодом 3, если данные использовать нельзя. Предупреждения (пропуски, нулевой спред) на код не влияют.

Данные делятся на три набора по датам: `holdout` — последние 24 месяца, `dev` — первые 70% остального, `test` — последние 30%. Границы печатает `npm run validate`. Набор выбирается флагом `--dataset`, по умолчанию `dev`.

Набор `holdout` закрыт: без флага `--i-understand-holdout` команда `backtest` завершается с кодом 4. Каждый запуск на `test` и `holdout` дописывается в [EXPERIMENTS.md](EXPERIMENTS.md).

Каждый прогон сохраняется в `reports/<набор>/<время>_<стратегия>/`: `report.md` и `report.json` — отчёт по разделам 9–10 ТЗ (метрики, разбивки, bootstrap, стресс-тест, вердикт), `trades.csv` — список сделок для ручной сверки, `run.json` — всё, что посчитал движок. Прогоны на `dev` в git не попадают. Страница «Отчёты» показывает сохранённые отчёты; на странице «Данные» сделки любого прогона можно показать на графике: стрелка — вход, точка — выход, пунктир — стоп и тейк.

Движок (`src/engine/`) ведёт один счёт на все пары, исполняет сигнал по открытию следующей свечи, проверяет стопы на свечах M15 (или H1 для дневной стратегии) и считает спред, комиссию, проскальзывание и своп. Как именно — в уточнении к разделу 7 ТЗ.

Настройки — в `config/default.json`. Своп задаётся в пипсах за ночь со знаком, как в MT5: отрицательный — платим. Параметры стратегий в конфиг не вынесены: они зафиксированы в ТЗ.
