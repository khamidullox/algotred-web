- `StrongLevelD1` — пробой сильного уровня с дневного графика с ретестом.

- Демо-торговля через MT5. Реальный счёт — только с ручным подтверждением каждой сделки.

## Наборы данных и журнал (сверх раздела 6)

- Зафиксировать границы наборов в файле. Сейчас они считаются от конца данных, и повторная выгрузка CSV сдвигает `holdout`.
- Записывать в `EXPERIMENTS.md` версию кода (git-коммит), чтобы запуск на `test` был привязан к конкретным правилам.
- Предупреждать, если стратегию уже запускали на `test`: по шагу 8 ТЗ такой запуск должен быть один.

## Веб-часть (сверх раздела 4а)

- Показать границы наборов `dev` / `test` / `holdout` на странице «Данные».
- Другие таймфреймы на графике (M1, M5, M30, H4): либо принимать такие экспорты MT5 только для графика, либо собирать из M1. Для бэктеста ТЗ оставляет экспорты MT5 на D1/H1/M15.
- Сборка свечей из M1 отдельной командой с кэшем на диске (`data/derived/`). Файлы M1 по 270 МБ, их нельзя разбирать на каждый запрос сайта.
- Подгрузка истории при прокрутке графика влево вместо окна в 1000 свечей и кнопок «Раньше» / «Позже».

- Выкладка сайта в интернет и база данных (Neon/Postgres) для свечей и отчётов. Сейчас сайт работает только локально, данные лежат в файлах.
- Загрузка истории по API вместо CSV. Отложено: у MT5 нет веб-API для истории, в сторонних источниках обычно нет исторического спреда, а ручная сверка сделок с графиком MT5 перестанет сходиться.
