Идеи, которые не входят в этап 1. Не реализовывать без отдельного решения заказчика.

## Из раздела 15 ТЗ

- `RectangleV1` — прямоугольник после импульса, только консервативный вход (закрытие за границей + ретест).
- `StrongLevelD1` — пробой сильного уровня с дневного графика с ретестом.
- Журнал ручных сделок с проверкой правил.
- Сигналы в Telegram для стратегий, прошедших `test` и `holdout`.
- Демо-торговля через MT5. Реальный счёт — только с ручным подтверждением каждой сделки.

## Веб-часть (сверх раздела 4а)

- Выкладка сайта в интернет и база данных (Neon/Postgres) для свечей и отчётов. Сейчас сайт работает только локально, данные лежат в файлах.
- Загрузка истории по API вместо CSV. Отложено: у MT5 нет веб-API для истории, в сторонних источниках обычно нет исторического спреда, а ручная сверка сделок с графиком MT5 перестанет сходиться.
